# UTILHUB — EXPANSÃO COMPLETA + REDESIGN PREMIUM 3D

Quero continuar o desenvolvimento do **UtilHub**, minha plataforma de ferramentas digitais gratuitas, desenvolvida com React, TypeScript e Vite.

Além de implementar as novas ferramentas, quero uma **grande evolução visual da plataforma**, transformando o UtilHub em um site moderno, impactante, tridimensional e altamente interativo.

O objetivo é criar uma experiência que impressione visualmente desde o primeiro acesso, com qualidade de apresentação semelhante à de plataformas tecnológicas premium.

**Não quero um site genérico, estático ou com aparência de projeto acadêmico básico. Quero uma identidade própria e memorável.**

## 1. REGRAS FUNDAMENTAIS

- Trabalhar diretamente nos arquivos existentes do UtilHub.
- Não criar outro projeto.
- Preservar todas as funcionalidades implementadas.
- Manter React, TypeScript e Vite.
- Não utilizar backend, APIs pagas ou serviços que gerem cobranças.
- Utilizar bibliotecas gratuitas e com licenças adequadas.
- Garantir funcionamento no GitHub Pages.
- Manter os dados e o processamento de arquivos localmente no navegador.
- Preservar os temas claro e escuro.
- Garantir responsividade para celulares, tablets e computadores.
- Não eliminar funcionalidades para melhorar a aparência.
- Não modificar outros projetos.
- Pedir autorização antes de operações destrutivas.

Analise a estrutura atual antes de realizar mudanças.

Não quero exageros que prejudiquem a leitura. O design deve ser impactante, mas organizado e profissional.

### Tecnologias sugeridas

Avaliar o uso de:

Utilize renderização WebGL apenas nos componentes em que o 3D real traga uma melhoria visual significativa.

# 9. PERFORMANCE E ACESSIBILIDADE

Esta parte é muito importante.

Não quero um site visualmente incrível que fique lento ou apresente travamentos.

Requisitos:

- Utilizar animações aceleradas por GPU quando apropriado.
- Priorizar transformações e opacidade em vez de propriedades caras de layout.
- Evitar animações que provoquem mudanças bruscas no posicionamento.
- Carregar componentes 3D somente quando necessário.
- Utilizar lazy loading e divisão de código.
- Limitar partículas e efeitos pesados.
- Liberar corretamente recursos WebGL, listeners e objetos temporários.
- Pausar animações que não estão visíveis.
- Adaptar efeitos para dispositivos menos potentes.
- Criar alternativas visuais quando WebGL não estiver disponível.
- Respeitar prefers-reduced-motion.
- Permitir uso completo por teclado.
- Preservar contrastes legíveis e áreas de clique adequadas.
- Não usar efeitos de hover como única forma de acessar informações.
- Garantir que todos os elementos importantes funcionem por toque.

O 3D deve enriquecer a experiência, nunca comprometer a utilização.
